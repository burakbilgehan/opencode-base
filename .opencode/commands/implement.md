Read the spec file at specs/$ARGUMENTS.md and implement it following the spec-driven workflow.

Steps:
1. Read the full spec file at specs/$ARGUMENTS.md
2. Check its status (must be `in-progress`)
3. Review the acceptance criteria and technical approach
4. Present your implementation plan and confirm with the user before writing code
5. Implement step by step, writing tests alongside code
6. Check off acceptance criteria as they are satisfied
7. Run the full test suite after implementation
