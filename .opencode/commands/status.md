Check the overall project status:

1. Run `git status` to see pending changes and current branch
2. Check if there are any failing tests (detect test framework and run)
3. List all spec files in the `specs/` directory and read each one's Status field
4. Summarize:
   - What's currently in progress
   - What specs are in draft/review/done
   - Any uncommitted changes
   - Suggested next steps
